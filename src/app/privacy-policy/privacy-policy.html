When using Join, users may enter information such as names, email addresses, tasks, contacts, descriptions, dates and assigned team members.

Users may create an account or use the application as a guest. When an account is created, the provided login information may be stored in the database used by the project.

Users are responsible for choosing a secure password and for keeping their login information confidential.

5. Storage of Data

Data entered into Join may be stored using Supabase. The data remains stored until it is deleted by the user, removed by the project team or the project database is reset.

Since Join is a training project, the availability and permanent storage of data cannot be guaranteed.

6. Sharing of Data

Personal data will not be transferred to third parties unless this is technically necessary to operate the application or required by law.

7. Cookies and Local Storage

Join may use browser storage technologies such as local storage or session storage to save login information, user preferences or application data.

This data can be removed by clearing the browser storage or deleting the browser data.
